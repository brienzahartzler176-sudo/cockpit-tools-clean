# Cockpit Tools Clean

This community edition is adapted from [Cockpit Tools v1.4.2](https://github.com/jlcodes99/cockpit-tools/tree/v1.4.2) by jlcodes99 and upstream contributors, revision `586d409df963610a51a48da24256ffd30b924493`. The [hect0x7 community edition](https://github.com/hect0x7/cockpit-tools/commit/43579441ee88e724933cdc00e26b684f04f07f93) provided a reference for removing the promotion feed.

Cockpit Tools Clean disables upstream promotional announcements and sponsor routes, removes sponsored defaults, referral parameters from built-in provider links, and promotional controls, and uses manual releases. The application has its own display name and identifier.
